## 已确定的约定

- 系统主题通过 JS 对象、Svelte context 和 getter 工作；iem 已取消，不实现 CSS 变量主题。
- 根 Provider 默认 lightTheme，嵌套继承。组件必须在 Provider 后代中使用。
- useTheme/useLocale/useLang 分开；没有 UiConfig/useConfig。
- 系统 token 键统一带下划线，如 _primary、_md；主题声明保持同名，例如 s.color._primary、s.color.raw('_primary')，Icon 的 color="_primary"、size="_md" 同理。
- 系统 theme 采用完整对象替换，嵌套主题由各自的 UiCss 消费。通用 token 各组件直接复用；组件专用值就近写在组件内部，通过同一套 CSS 工具生成声明，class 是外部样式定制入口。不建立组件 token 注册、注入、覆盖或合并基础设施。
- Icon 的 size/color/strokeWidth/verticalAlign 默认值在 $props() 中声明为 _md/inherit/2/-0.125em；支持系统 token 与对应原生 CSS 输入。
- 所有后续组件的外观 props 默认使用 Parameters<UiCss['属性']['raw']>[0]；通用、常用且需要统一定制的外观 token 进入 CSS 工具主题树，专用值在组件内固定。确有需求时局部收窄或扩展输入并实现对应转换，不引入组件 token 基础设施。示例和 Exclude 的开放字符串边界见主题设计文档。
- 系统字号 _lg 是 20px、_xl 是 24px，Icon 直接使用同名档位。描边与其他外观属性一样直接使用 raw()，没有 bx 或关键字分支。
- 本次没有改动 zerodep-css；仍消费 catalog 固定的 0.1.3，不依赖本机 link、私有补丁或绝对路径。

## 新机器准备

使用 Node 24 和 package.json 指定的 pnpm 10.34.5。在仓库目录执行：

```powershell
git fetch origin
git switch codex/dependencies-and-quality
git pull --ff-only
pnpm install --frozen-lockfile
pnpm sync
pnpm lsp:setup
pnpm check
pnpm dev
```

信任并重新打开项目后核对 LSP MCP 是否连接。.codex/config.toml 为本机生成文件，不复制旧机器路径；dist/build/.svelte-kit 也不必迁移。若用户级 .npmrc 使用 NPM_TOKEN，占位变量需要由新机器的进程环境提供，令牌不放入仓库。
